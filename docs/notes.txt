revision log
	2013-06-25 10:24pm, now selects word under cursor if there is no text selected
	2013-10-14, sublime text 3 version added on the st3 branch
	2026-07-27, rewritten for python 3 / ST4
		the old scrape of google's results page for "Did you mean" / "Showing results for"
		stopped working -- google removed that markup, so the regex never matched and the
		plugin silently did nothing. verified 0/5 matches on known misspellings.
		now uses the suggest endpoint w/ client=psy-ab, the one client that returns explicit
		spell-correction metadata: za = corrected, zb = what you typed. that flag is what
		makes silent replacement safe -- no flag, no change to your text.
		fallback accepts a top suggestion only if it reads as a respelling (same word count,
		small per-word edit distance, same first letter), which stops "receive" -> "received"
		and stops phrases being extended into a full search query.
		also: all cursors checked in one pass (replaced back to front), case preserved,
		leading/trailing whitespace preserved, runs off the UI thread.
		verified 39/39: 19 misspellings corrected, 20 correct phrases left alone.
		st2/st3 branches retired, everything on master. package control channel PR:
		https://github.com/sublimehq/package_control_channel/pull/9501
